EduTech Solutions – Windows Server Infrastructure
About the Project

This project was completed as a group assignment for Operating Systems 261.

The project was based on a case study for EduTech Solutions, a mid-sized e-learning company that wanted to modernise its IT infrastructure to support remote work, improve security, and prepare for hybrid cloud integration with Microsoft Azure.

As part of the project, we designed and implemented a Windows Server 2019-based domain infrastructure in a virtual environment.

Project Objectives

The main objectives of the project were to:

Set up a Windows Server 2019 environment.
Configure a domain controller using Active Directory.
Create and manage users, groups, computers, and organisational units.
Configure DNS and DHCP services.
Implement Group Policies and user restrictions.
Configure file services and DFS.
Provide remote access using RDS and VPN/DirectAccess.
Implement backup and monitoring solutions.
Apply security hardening measures.
Configure certificate services.
Integrate the on-premises Active Directory environment with Microsoft Azure.
Active Directory and Group Policy

The project included the design and implementation of a structured Active Directory environment.

This included:

Creating organisational units (OUs)

Creating users and groups

Managing computer accounts

Delegating administrative responsibilities

Creating and linking Group Policies

Enforcing password requirements and user restrictions

Configuring roaming and mandatory profiles

Remote Access and Security

Remote access was configured to support employees working outside the organisation.

The project also included security measures such as:

Security hardening
BitLocker
Disabling outdated services
Active Directory Recycle Bin
Microsoft Security Compliance Toolkit
Desired State Configuration
Certificate management
Azure Integration

The project included hybrid identity integration using Azure AD Connect.

We configured synchronisation between the on-premises Active Directory environment and Azure and demonstrated Password Hash Synchronization.
